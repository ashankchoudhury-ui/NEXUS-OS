02 / CONTEXT ARCHITECTURE

SPACES

Two distinct working contexts are the core product idea. Actual separation depends on Android's supported user/profile APIs and device firmware; this preview does not create or switch profiles.

NODE / 01

USER_SPACE

Personal identity. Daily apps, private files, personal notifications and the default environment.

NODE / 02

AGENT_SPACE

Dedicated work context for agent-facing tools, work accounts and automation interfaces.

Implementation gate: verify Work Profile / secondary-user support on the target Lava firmware before promising workspace isolation.

MODULES

Real app-state signals and safe, reversible policies. No process control implemented.

Android-supported profile management, if the device firmware exposes it.
